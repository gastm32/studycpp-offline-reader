# C++ 学习网 - 本地化阅读与抓取工具

本项目包含了从 [C++学习网 (https://www.studycpp.cn/)](https://www.studycpp.cn/) 抓取的全套教程文档，以及一个可以随时自动抓取最新更新内容的工具。

`C++学习网` 是一个非常优秀的中文 C++ 学习网站，教程深入浅出。为了方便大家使用 Obsidian、VS Code 等支持 Markdown 的工具进行离线沉浸式阅读和笔记整理，我制作了这个自动抓取项目。

## 项目特点

- **结构清晰**：自动按照原网站的章节目录分类摆放。
- **格式整洁**：自动剔除网页的导航栏、评论区，并且对含有行号的代码块进行了完美的 Markdown 代码高亮适配。
- **自动化**：提供了一键抓取脚本，一键同步最新内容。

## 如何使用“一键抓取”脚本

为了方便在任何电脑上随时更新内容，项目中包含了针对 Windows 和 Mac/Linux 系统的“一键抓取”启动文件。

### 使用步骤

1. **安装 Python 环境**：
   本脚本依赖 Python。如果您的电脑还没有安装 Python，请前往 [Python 官网](https://www.python.org/) 下载安装。
   > **注意**：Windows 用户在安装 Python 时，请务必勾选底部出现的 **"Add Python to PATH"** 选项。

2. **运行脚本**：
   - **Windows 用户**：直接双击文件夹中的 **`一键抓取.bat`** 文件。
   - **Mac/Linux 用户**：双击运行 **`一键抓取_Mac.command`**（首次运行可能需要在终端中赋予权限，即执行 `chmod +x 一键抓取_Mac.command` ）。

3. **自动安装与抓取**：
   - 脚本会自动检查您的电脑环境。
   - 它会自动下载并安装所需的第三方库（`requests`, `beautifulsoup4`, `markdownify`），无需您手动配置。
   - 安装完成后，爬虫将自动开始工作，去网站拉取最新的文章，覆盖本地的 Markdown 文件。

4. **完成**：
   耐心等待黑框跑完并显示“抓取完毕”，所有的学习文档就已经更新好啦！
