# C++ Lambda 表达式全解析及笔试面试真题

## 一、 知识点全览

### 1. 什么是 Lambda 表达式？
Lambda 表达式是 C++11 引入的一种匿名函数定义方式。它的本质是一个**匿名函数对象（Functor/闭包）**，编译器在底层会将其转换为一个带有 `operator()` 的匿名结构体或类。

### 2. 基本语法
```cpp
[capture_list](parameters) mutable exception_specification -> return_type {
    // 函数体
}
```
*   **capture_list (捕获列表)**：用于捕获上下文中的变量，以供 lambda 表达式内部使用。（**必填**）
*   **parameters (参数列表)**：与普通函数的参数列表相同。如果不传递参数，可以省略 `()`。（可选）
*   **mutable (修饰符)**：默认情况下，lambda 的 `operator()` 是 `const` 的。加上 `mutable` 可以取消其常量性，允许修改按值捕获的变量副本。（可选）
*   **exception_specification (异常说明)**：如 `noexcept`，指定是否抛出异常。（可选）
*   **return_type (返回类型)**：使用后置返回类型 `->`。如果函数体只有一个 `return` 语句，或者返回 `void`，编译器可以自动推导，此时可省略。（可选）
*   **函数体**：函数的具体实现。（**必填**）

### 3. 捕获列表详细说明（核心易考点）
*   `[]`：不捕获任何外部变量。可以隐式转换为普通的函数指针。
*   `[var]`：按**值**捕获变量 `var`。
*   `[&var]`：按**引用**捕获变量 `var`。
*   `[=]`：按**值**捕获外部作用域中的所有变量（包括 `this` 指针）。
*   `[&]`：按**引用**捕获外部作用域中的所有变量（包括 `this` 指针）。
*   `[=, &a, &b]`：按值捕获所有变量，但 `a` 和 `b` 按引用捕获。
*   `[&, a, b]`：按引用捕获所有变量，但 `a` 和 `b` 按值捕获。
*   `[this]`：捕获当前类的 `this` 指针，使得 lambda 可以访问该类的成员变量和函数。

### 4. 底层实现原理
当编译器遇到 lambda 表达式时，会生成一个闭包类（Closure Class）：
1.  **捕获变量转化为成员变量**：捕获列表中的变量会成为该类的成员变量。
2.  **重载 operator()**：函数的逻辑放在这个类的 `operator()` 重载函数中。默认情况下，这个重载函数是 `const` 的。
3.  **构造函数**：编译器生成一个构造函数来初始化这些成员变量（即完成捕获）。

### 5. C++14/17 演进
*   **C++14 泛型 Lambda**：参数可以使用 `auto`（底层实现是模板的 `operator()`）。
    ```cpp
    auto add = [](auto x, auto y) { return x + y; };
    ```
*   **C++14 初始化捕获**：可以在捕获列表中初始化变量（常用于捕获 `std::unique_ptr` 等不可拷贝对象）。
    ```cpp
    auto ptr = std::make_unique<int>(10);
    auto lambda = [p = std::move(ptr)]() { /* 使用 p */ };
    ```
*   **C++17 constexpr Lambda**：Lambda 可以被声明为 `constexpr`，用于编译期计算。

## 二、 笔试/面试常考题目及原题

### 题目 1：生命周期陷阱（悬空引用）—— 经典高频题
**题目描述**：以下代码有什么问题？会导致什么后果？
```cpp
#include <iostream>
#include <functional>

std::function<void()> make_lambda() {
    int x = 10;
    return [&x]() { std::cout << x << std::endl; };
}

int main() {
    auto func = make_lambda();
    func();
    return 0;
}
```
**答案解析**：
*   **问题**：导致悬空引用（Dangling Reference），引发未定义行为（Undefined Behavior）。
*   **解析**：`make_lambda` 函数内部的局部变量 `x` 在函数返回时就会被销毁。而返回的 lambda 表达式通过**引用**捕获了 `x`。当在 `main` 函数中调用 `func()` 时，它试图访问一个已经被销毁的内存，导致崩溃或输出随机垃圾值。
*   **解决方案**：将捕获方式改为按值捕获 `[x]` 或 `[=]`。

### 题目 2：mutable 关键字的考察
**（某大厂笔试原题）题目描述**：以下程序的输出是什么？
```cpp
#include <iostream>

int main() {
    int x = 0;
    auto f = [x]() mutable { 
        x++; 
        std::cout << "Inner: " << x << ", "; 
    };
    f();
    f();
    std::cout << "Outer: " << x << std::endl;
    return 0;
}
```
**答案与解析**：
*   **输出**：`Inner: 1, Inner: 2, Outer: 0`
*   **解析**：
    1.  由于使用了 `[x]` 值捕获，`f` 内部保存了 `x` 的一个副本。
    2.  加入了 `mutable` 关键字，使得这个副本可以在 lambda 内部被修改。
    3.  闭包对象 `f` 的生命周期跨越了两次调用，所以内部副本 `x` 的状态被保留了（第一次加到1，第二次加到2）。
    4.  外部的 `x` 不受影响，仍为 0。

### 题目 3：Lambda 与函数指针的转换
**题目描述**：为什么有些 lambda 可以直接赋值给函数指针，而有些不行？请举例说明。
```cpp
void (*pFunc1)(int) = [](int a) { std::cout << a << std::endl; }; // A
void (*pFunc2)(int) = [&](int a) { std::cout << a << std::endl; }; // B
```
上述代码中 A 和 B 哪行会编译报错？为什么？
**答案解析**：
*   **B 行会编译报错**。
*   **原因**：只有**捕获列表为空 `[]`** 的 lambda 表达式才可以隐式转换为普通的函数指针。因为捕获了变量的 lambda 会生成带有状态（成员变量）的类对象，它无法被简单地映射为一个静态的、无状态的 C 风格函数指针。A 行捕获列表为空，可以转换；B 行捕获了引用，无法转换。

### 题目 4：this 指针的捕获隐患
**题目描述**：在类成员函数中使用 `[=]` 捕获时，有什么潜在风险？
**答案解析**：
在类成员函数中，`[=]` 不仅会值捕获局部变量，还会隐式捕获 `this` 指针（实际上是指针的值拷贝）。这意味着你可以在 lambda 内部操作类的所有成员。
**风险**：如果 lambda 的生命周期长于当前对象的生命周期（例如将 lambda 抛到另一个线程或回调队列），当对象被销毁后，lambda 内部仍持有 `this` 指针并尝试访问类成员，就会导致段错误（访问已释放的内存）。C++20 引入了 `[=, this]` 显式捕获和 `[=, *this]` 按值拷贝对象来缓解此类问题。

### 题目 5：Lambda 和 std::function 的区别与联系（面试常问）
**题目描述**：什么是 `std::function`？它和 Lambda 表达式有什么区别？什么时候该用哪个？
**答案解析**：
*   **Lambda**：是语言级别提供的语法糖，用于生成匿名的函数对象（闭包类）。每个 lambda 都有一个独一无二的未命名类型。编译器可以直接内联，效率极高。
*   **std::function**：是 C++ 标准库中的多态函数包装器，可以用来存储任何可调用实体（普通函数、lambda、bind表达式、仿函数等）。它内部使用了类型擦除（Type Erasure），可能涉及动态内存分配，调用时也有额外的性能开销（虚函数调用等）。
*   **使用场景**：
    *   局部使用、传给 STL 算法（如 `std::sort`）时，**优先使用 auto 接收 Lambda 表达式**。
    *   当需要把可调用对象存储起来（例如作为类的成员变量、存入容器、跨边界传递）且类型需要统一时，**使用 `std::function`**。
