**16. 阅读以下代码并写出其输出，解释为什么。**
```cpp
void passByValue(int* p) { p = new int(10); }
void passByRef(int*& p) { p = new int(20); }
int main() {
    int* ptr1 = nullptr;
    int* ptr2 = nullptr;
    passByValue(ptr1); // ... 打印 ptr1
    passByRef(ptr2);   // ... 打印 ptr2
}
```
> **你的答案：** 输出：ptr1 is null. passByRef(ptr2)不成功，ptr2应该要引用左值
> **正确答案：** 输出：ptr1 is null. 20
> **得分：** 3/8
> **深度解析：** 你的思路摸到门槛了！但有个小误区。`ptr2` 本身就是一个指针**变量**，变量是有内存地址的，它**就是一个左值**！所以 `int*& p` (读作：指向 int 的指针 的 引用) 是完全合法的。
> 1. `passByValue(ptr1)`：你传进去的是指针的“复印件”，函数里修改复印件，原件 `ptr1` 丝毫不受影响，还是 null。
> 2. `passByRef(ptr2)`：你传进去的是指针的“引用”（原件），函数里给它 new 了一块新内存，原件 `ptr2` 确实被改变了，指向了这块存着 20 的内存。

**17. 以下类定义中存在至少两个严重的潜在问题。请指出并说明如何修复。**
```cpp
class IntArray {
private:
    int* data;
    int size;
public:
    IntArray(int s) : size(s) { data = new int[size]; }
    ~IntArray() { delete data; } // 【提示：仔细观察释放内存的方式】
    int& operator[](int index) { return data[index]; }
};
int main() {
    IntArray arr1(10);
    IntArray arr2 = arr1; // 发生拷贝
    arr2[0] = 5;
    return 0;
}
```
> **你的答案：**
> 问题1及修复：IntArray(int s) : size(s)改成 不知道。delete data;改成delete data[];
> 问题2及修复：IntArray arr2 = arr1;  其实也不知道
> **正确答案与解析：**
> 1. **浅拷贝导致双重释放（Double Free）崩溃**：`arr2 = arr1;` 发生的是默认浅拷贝，`arr1` 和 `arr2` 内部的 `data` 指向了同一块堆内存。析构时，同一块内存被释放两次！**修复**：自己写拷贝构造函数进行深拷贝，或者干脆用 `std::vector`。
> 2. **析构释放错误**：`delete data` 是错的，因为申请的是数组 `new int[size]`，必须用 `delete[] data;`。你答对了这一点！
> **得分：** 4/8

**19. [类与对象] 什么是类的初始化列表？为什么对于常量成员（`const`）或引用成员，必须使用初始化列表而不能在构造函数体中赋值？**

> **正确答案与解析：**
> C++ 在创建一个对象时分两步：1. 分配内存并初始化（诞生）；2. 进入构造函数的 `{ }` 里进行赋值（穿衣服）。
> 对于 `const` 常量和 `引用` 来说，它们性格刚烈，必须在**诞生**的那一刻就被安排好（初始化），决不允许生下来之后再去修改它。所以，必须使用**初始化列表**（冒号语法），在诞生阶段就搞定它们。如果写在 `{ }` 里面，那就属于“诞生后的赋值”，编译器会报错。

**20. 综合编程题：简易购物车系统**
> **你的答案：** 空白
> **满分参考代码与解析：**
> 你完全留白了。其实这道题是把前面的知识点串起来用的。以下是现代 C++ 的标准写法，你可以仔细体会一下。

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

struct Item {
    std::string name;
    double price;
};

class ShoppingCart {
private:
    std::vector<Item> items; // 使用容器管理商品
public:
    void addItem(const std::string& name, double price) {
        items.push_back({name, price});
    }

    double getTotalPrice() const {
        double total = 0.0;
        // 使用基于范围的 for 循环
        for (const auto& item : items) { 
            total += item.price;
        }
        return total;
    }

    void sortByPrice() {
        // 使用 std::sort 配合 Lambda 表达式排序
        std::sort(items.begin(), items.end(), [](const Item& a, const Item& b) {
            return a.price < b.price;
        });
    }

    void printCart() const {
        std::cout << "--- 购物车商品列表 ---" << std::endl;
        for (const auto& item : items) {
            std::cout << item.name << " : $" << item.price << std::endl;
        }
    }
};

int main() {
    ShoppingCart cart;
    cart.addItem("Apple", 3.5);
    cart.addItem("Banana", 2.0);
    cart.addItem("Milk", 5.5);

    std::cout << "排序前：" << std::endl;
    cart.printCart();
    
    cart.sortByPrice();
    
    std::cout << "\n按价格排序后：" << std::endl;
    cart.printCart();
    
    std::cout << "\n购物车总价: $" << cart.getTotalPrice() << std::endl;
    return 0;
}
```
