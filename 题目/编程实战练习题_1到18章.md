## 🟢 难度一：基础控制流与字符串 (易)
**题目：简易密码验证器**

**需求：**
1. 提示用户输入一个密码（使用 `std::string` 和 `std::cin`）。
2. 检查密码是否合法，合法的条件是：**长度必须大于等于 8 个字符**。
3. 如果密码太短，打印“密码太短，请重新输入”，并**循环**要求用户继续输入。
4. 如果密码合法，打印“密码设置成功！”并结束程序。

**考察知识点：** `while` 循环、`if` 判断、`std::string` 的 `.length()` 或 `.size()` 方法。

## 🟡 难度二：`std::vector` 与引用传参 (中)
**题目：成绩过滤器与计算器**

**需求：**
1. 在 `main` 函数中，创建一个 `std::vector<int>`，里面预先填入一些成绩，比如 `{45, 85, 90, 55, 78, 100, 30}`。
2. 编写一个独立的函数 `double calculateAverage(const std::vector<int>& scores)`。
   - **注意**：这里必须使用 `const std::vector<int>&` 传参，体会避免拷贝的优势。
3. 在这个函数内部，过滤掉所有不及格（小于 60 分）的成绩，然后计算并返回及格成绩的**平均分**。
4. 在 `main` 函数中调用该函数，并打印出最终的平均分。

**考察知识点：** `std::vector` 的遍历 (推荐用范围 `for` 循环)、`const &` 引用传参、算术运算。

## 🟠 难度三：面向对象初体验 (中难)
**题目：简易银行账户类**

**需求：**
1. 设计一个名为 `BankAccount` 的类 (Class)。
2. **私有 (private) 成员：**
   - 账号名称 `std::string accountName`
   - 账户余额 `double balance`
3. **公有 (public) 成员：**
   - 一个**构造函数**：接受账号名称和初始余额作为参数，并使用**初始化列表**给成员变量赋值。
   - `void deposit(double amount)`：存款方法，将金额加到余额中。
   - `void withdraw(double amount)`：取款方法。要求：如果余额不足，打印“余额不足，取款失败”，否则扣除金额并打印成功。
   - `double getBalance() const`：获取当前余额的方法。注意：这个方法只读不改，所以**必须**加上 `const` 修饰符。
4. 在 `main` 函数中，实例化一个 `BankAccount` 对象，存点钱，取点钱，最后打印余额。

**考察知识点：** 类的封装（public/private）、构造函数与初始化列表、`const` 成员函数。

## 🔴 难度四：综合大考验 (难)
**题目：班级花名册系统 (Class 与 Vector 的结合)**

**需求：**
1. 设计一个简单的类 `Student`，包含私有成员：名字 (`std::string name`) 和 分数 (`int score`)。写好构造函数和获取名字、分数的 `get` 方法。
2. 设计另一个类 `Classroom`。
   - 它的私有成员应该是一个用于存放学生的动态数组：`std::vector<Student> students`。
   - 提供一个方法 `void addStudent(const Student& s)`，使用 `push_back` 将学生添加到花名册中。666666666
   - 提供一个方法 `void printTopStudent() const`，遍历内部的 `students` 集合，找出分数最高的学生，并打印出他/她的名字和分数。
3. 在 `main` 函数中，创建一个 `Classroom` 对象，往里面添加 3 个 `Student` 对象，最后调用 `printTopStudent()` 看看谁是第一名。

**考察知识点：** 复合类型（把自定义的 Class 放进 STL 容器中）、类的交互、算法逻辑寻找最大值。
